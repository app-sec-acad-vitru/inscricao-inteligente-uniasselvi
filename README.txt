PROTÓTIPO V1 — INSCRIÇÃO INTELIGENTE UNIASSELVI

Como testar:
1. Abra index.html em um navegador.
2. Escolha uma modalidade.
3. Para Segunda Licenciatura, teste origem Pedagogia e depois outra licenciatura.
4. Para Formação Pedagógica, selecione um curso, uma origem e envie qualquer PDF/JPG/PNG para simular o documento.
5. Área administrativa: botão "Área administrativa" > PIN 2026.

Observações:
- Este é um protótipo navegável, sem backend.
- Os registros ficam apenas no localStorage do navegador.
- A tabela de afinidades incluída é uma base DEMONSTRATIVA para testar o fluxo. Antes de produção, ela deve ser substituída pela tabela institucional estruturada e versionada.
- A leitura real de diploma/histórico (OCR/IA), persistência, autenticação segura e integração com base de inscrições são etapas posteriores.
- O catálogo público da UNIASSELVI é muito maior; a arquitetura foi feita para receber o catálogo completo por JSON/API, sem hard-code da lista final.
